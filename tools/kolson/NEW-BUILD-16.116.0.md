## про текст баннера

В этой сборке 39 строк с кириллицей, все — UI лаунчера (пресеты оружия, Custom,
модели, вход NEIZZIR). Строки про «сторонние библиотеки» нет ни в UTF-8, ни в
UTF-16, ни под однобайтовым XOR (перебор 1..255 по всему файлу). Значит её
источник — не libkolson и не dex (проверены `classes4.dex`, `classes8.dex`).

## сделано

Группа `auth` (проверка команд/подписи входа) уже обходится в этой сборке:
10 проверок в функции `0x2fca24..0x2fcdc0` → `nop`, см. `KOLSON_PATCHES_B` в
`kolson_patches.h`. Патчер определяет сборку по probe `0x2fcc84 == 0x2a1f03f3`,
`make one-test` → `patched=10 failed=0`, runtime == offline байт в байт.

## что дальше

1. Взять якоря выше и заново найти конкретные проверки в этой сборке
   (weapon-чек, гейт подписи, crash-hook) — по xref-ам от строк, а не по старым
   адресам.
2. Для каждой найденной проверки — тот же приём: `mov w0,#1; ret` / `nop`,
   запись в `kolson_patches.h` с новыми `expect`-словами (патчер проверяет их
   перед записью, поэтому чужая сборка не портится).
3. Стелс-часть (`kolson_stealth.c`) от сборки не зависит: она прячет сам шим по
   именам, а не по адресам.
